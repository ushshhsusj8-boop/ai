# Global search keyboard and result budgets

Reload the page and open Search or press Ctrl/Cmd K. From the query, ArrowDown selects the first result and ArrowUp selects the last. Navigation wraps at either end, and Enter opens the selected item. Empty results and IME composition preserve query focus.

The displayed cap follows the current searchDisplay policy. A 75-result limit is described as 75, while a partial list displays only the actual result count.

Search still covers only the supplied workspace data already loaded for the current account. These changes add no model calls, remote data access, account privileges or indexing.
