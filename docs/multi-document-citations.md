# Citation links for later documents

Reload open tabs after updating. Registered document references in an answer are no longer limited to the first three documents. References such as [资料4·片段1] remain interactive when the answer contains a matching saved source.

Click a citation to open that answer's source, then select the original-text action to locate and highlight the exact saved excerpt. Tab and Enter activate citation buttons; Escape closes the original-text reader.

Only exact IDs present in that answer's source map become links. Missing sources, inline code and fenced code remain plain text. Numeric web-source links retain their existing behavior.

This does not raise the configured document count, expand model context, rewrite prior answers or imply that the model read the entire document. Changed or deleted files retain the old excerpt rather than guessing a new location.

Synthetic browser checks cover documents 4, 10 and 20, existing references, exact original positions, missing sources/code, reload, keyboard actions and desktop/mobile layout. Real accounts, model calls and user code are not used.
