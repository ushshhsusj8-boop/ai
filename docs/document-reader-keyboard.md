# Document reader keyboard navigation

After reloading the page, open a saved document and use its search field.

Changing a multiword query and immediately pressing Enter starts at its first result, including when the old and new queries have equal result counts and the same first matched word. Once the search results have updated, Enter advances and Shift+Enter moves back.

IME composition does not prematurely navigate. No-match searches disable navigation. The existing 2000-result bound, exact source validation and original document contents are unchanged.

Use Close original to dismiss the reader. In Chrome, Escape in a focused search field may first clear the query; Escape from the close button dismisses the reader.
