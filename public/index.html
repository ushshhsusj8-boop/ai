键盘操作说明

  • Tab / Shift + Tab：依次移动焦点；Enter 或空格：操作按钮。
  • Ctrl / Command + K：搜索对话、项目、资料与文稿；Ctrl / Command + Shift + F：查找当前对话。
  • Ctrl / Command + Shift + O：开启新对话，当前草稿保留。
  • 默认 Enter 发送、Shift + Enter 换行；设置中心可改为 Ctrl / Command + Enter 发送。输入法选字不会发送。
  • Esc：关闭弹窗或手机侧栏，焦点返回入口；手机工具中的弹窗关闭后返回“工具”。
  • 网页开头的“跳转到消息输入框”可以跳过导航。手机可用“工具”访问模型与设置。
