# Local secret files

This folder is ignored except for this document. Generate a gateway_access_token containing at least 32 random characters, and create one provider key file: deepseek_api_key, nvidia_api_key, gemini_api_key, openrouter_api_key or openai_api_key. Configure matching environment settings in your local .env file.

Do not commit real values or place them in screenshots or issue reports. Optional local workspace settings are encrypted here; keep the encryption key and settings together in a private backup. See docs/SETUP.md.
